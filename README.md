# TECHSMART

Extraia o conteúdo deste ZIP na raiz do repositório. O index.html, a pasta assets e o vercel.json ficam no mesmo nível. O site é estático e vem pronto para publicação.

Na Vercel, mantenha a raiz do projeto apontando para a raiz do repositório. O vercel.json aplica os ajustes de cache e desativa a instalação e a compilação.

Para ativar o sitemap, preencha a URL pública em sitemap.xml.example e renomeie para sitemap.xml.
